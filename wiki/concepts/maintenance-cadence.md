# Maintenance Cadence (recurring jobs)

The automated upkeep layer that [[bryce-robbie]] calls the **"lazy unlock"** in
[[lazy-obsidian-method-brief]]: a set of recurring jobs on daily / nightly / weekly
cadences that keep an [[llm-knowledge-base]] alive "without making maintenance a job."

## The three cadences

| Cadence | Inputs | Outputs | Purpose |
|---|---|---|---|
| **Daily ingest** | Web clips, notes, voice memos | Cleaned notes, wiki-ready pages, ingest summary | Get messy inputs in — don't overthink |
| **Nightly review** | Daily notes, lessons, agent logs & memory | Refreshed dashboards, memory updates, backups | Tidy-up + critical priority refresh |
| **Weekly vault** | Memory, dashboards, topic gaps | Weekly review, gaps list, next-step items | Set focus areas for the coming week |

## Why it matters

This is the operational complement to the principle "Capture messy. Process later. Let
the vault improve over time" (see [[lazy-obsidian-method]]). Where
[[karpathy-llm-knowledge-bases]] describes ingest and [[wiki-linting]] as on-demand
activities, this brief schedules them on a fixed rhythm — turning maintenance from a
manual chore into background automation. The weekly "gaps list" output is a scheduled
form of the gap-finding that [[wiki-linting]] and [[absence-first-research]] do.
