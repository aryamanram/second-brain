# PARA Method

An organizational taxonomy that sorts all information into four top-level folders:
**P**rojects, **A**reas, **R**esources, **A**rchive. Originated by Tiago Forte / Forte
Labs (fortelabs.com/blog/para). In [[lazy-obsidian-method-brief]] it is the **"Structure"
layer** of the [[lazy-obsidian-method]] stack.

## Role in the lazy method

PARA gives the vault (and the agents working in it) a consistent place to put things.
The brief treats it as **optional-but-foundational**: step 1 of the setup is "Set up PARA
folders — only critical if you have no structure. Align your agents to it." In other
words, if a knowledge base already has a working structure (as this wiki does, with its
`raw/` + `wiki/{sources,entities,concepts,...}` layout), PARA is not required; its value
is giving structure to an otherwise unstructured vault.

## Relation to this wiki's structure

This wiki uses a domain-specific taxonomy (sources / entities / concepts / syntheses /
comparisons / questions) rather than PARA. PARA is a generic personal-knowledge taxonomy;
the two solve the same "where does this go?" problem at different levels of generality.
